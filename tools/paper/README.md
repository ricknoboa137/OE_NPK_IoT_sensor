# Manuscript analysis scripts

These scripts produce and verify the figures and numbers of the Agriculture
manuscript. The code is kept here. The readings of the module are in
`database/sensor_log.csv.gz` of this repository; the laboratory, satellite and
figure-source data are kept under version control in the paper repository, in
its `data/` folder. The scripts read nothing from anywhere else. Point them at
a checkout of the paper:

    set PAPER_DIR=C:/path/to/Agriculture-4351955

Everything below runs with the base Anaconda interpreter
(`C:/Users/User/anaconda3/python.exe`), from this folder.

## Reproducing the figures

| figure | command |
| --- | --- |
| `Pic/NDMI_station.png` | `python ndmi_station_analysis.py` |
| `Pic/SZ24_field.png` | `python make_sz24_figure.py` |

The other figures of the manuscript are photographs, CAD renderings and
screenshots, and are not generated by code.

## Reproducing and checking the numbers

| script | what it does |
| --- | --- |
| `audit_paper_numbers.py` | recomputes every figure quoted in the manuscript from the data and checks that it appears in the .tex |
| `paper_analysis.py` | the nutrient-channel characterisation: relations between the outputs, the zero floor, laboratory correlations |
| `insertion_analysis.py` | the two-soil campaign: nitrogen output against moisture output across insertions, and settling after insertion |
| `solve_paper_cal.py` | the two-soil calibration: means per soil, fitted A and B, direction against the laboratory |
| `ndmi_station_analysis.py` | the satellite case study; also writes `ndmi_station_results.json`, which the audit reads |
| `check_manuscript_tex.py` | structural checks on the .tex: highlighted spans that soul cannot typeset, that cross a blank line or are nested; brace balance; cross-references; table columns |

## How the versioned data were produced

These two scripts need inputs that are not versioned, and are kept as the record
of how the data files were derived. They do not need to be run again.

| script | reads | writes |
| --- | --- | --- |
| `export_sensor_log.py` | the live Node-RED database `DB_01.db` | `database/sensor_log.csv.gz` |
| `build_ndmi_dataset.py` | the raw NDMI tiles, the field shapefile and the station file (needs rasterio and geopandas: `tf210` environment) | `data/ndmi_csolnok_field.npz`, `station_csolnok_daily.csv`, `field_csolnok.geojson`, `ndmi_field_meta.json` |

`paper_data.py` holds the file locations and loads the sensor log into an
in-memory SQLite table, so the queries in the scripts are unchanged.

`make_paper_revision.py` is historical: it built the first revision from the
original .tex. Do not re-run it; the manuscript has been edited directly since.
